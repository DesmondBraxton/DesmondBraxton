## Featured Data Engineering Project

### 🚕 NYC Yellow Taxi Data Pipeline

An end-to-end data engineering project built around NYC TLC Yellow Taxi trip records.

The architecture demonstrates a modern data pipeline incorporating:

- Multi-file Parquet ingestion
- PySpark transformation pipelines
- Data-quality validation and quarantine
- Feature engineering
- Taxi-zone dimensional enrichment
- Broadcast joins
- Partitioned Parquet datasets
- Raw and curated data layers
- AWS S3 data-lake architecture
- Amazon Athena analytical SQL
- Amazon Redshift warehouse design
- Modular and testable pipeline components
